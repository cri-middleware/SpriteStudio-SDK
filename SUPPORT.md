# Support Guide

Thank you for using SpriteStudio7-SDK! We want to ensure you have the best experience possible. Please use the following channels to get help, report issues, or suggest improvements.

## 🛠️ GitHub Issues (Public)
For most cases, please use [GitHub Issues](../../issues). This is the best place for:
- **Questions**: If you're unsure how to use a specific feature.
- **Feature Requests**: If you have ideas for new features or improvements.
- **Bug Reports**: If you've found a problem in the SDK.

Before opening a new issue, please search existing issues to see if your topic has already been discussed.

## 🔒 Private Inquiries & Large Files
If you need to report a sensitive issue, require a private consultation, need to send large reproduction data (e.g., `.sspj` projects), or require support with contractual guarantees, please use our official **Help Center**:

👉 [**CRI Middleware Help Center (Inquiry Form)**](https://www.webtech.co.jp/help/en/spritestudio7/inquiries/ssplayer_tool/)

*Note: For reproduction data, please use the file upload feature within the Help Center form.*

## 日本語でのサポート (Support in Japanese)

SpriteStudio7-SDK をご利用いただきありがとうございます。ご質問や不具合の報告は、以下の窓口をご利用ください。

### 🛠️ GitHub Issues (公開)
一般的なご質問、ご要望、不具合のご報告は [GitHub Issues](../../issues) へ投稿してください。
- **質問**: 使い方がわからない場合など。
- **要望**: 新機能や改善のアイデアがある場合。
- **不具合**: SDK の動作に問題がある場合。

投稿前に、同様の内容が既に報告されていないか、既存の Issue を検索してください。

### 🔒 非公開でのお問い合わせ・データの送付
非公開での相談を希望される場合、再現データ（`.sspj` プロジェクトなど）を送付いただく必要がある場合、または契約に基づくサポートが必要な場合は、公式の**ヘルプセンター**をご利用ください。

👉 [**ヘルプセンター（お問い合わせフォーム）**](https://www.webtech.co.jp/help/ja/spritestudio7/inquiries/ssplayer_tool/)
