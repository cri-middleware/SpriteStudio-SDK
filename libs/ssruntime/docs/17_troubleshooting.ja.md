# トラブルシューティング

Player 実装中やビルド時に発生する、よくある問題とその解決方法です。

## Windows 環境でのリンクエラー (C++)

`libssconverter` や `libssruntime` の静的ライブラリ (.lib) を Windows の C++ プロジェクトで利用する際、未解決の外部シンボル（LNK2019 / LNK2001）が発生することがあります。

その場合は、プロジェクトのプロパティから、以下の標準ライブラリを明示的にリンクするように設定してください。

- **Userenv.lib**
- **Bcrypt.lib**
- **Ntdll.lib**
- **Ws2_32.lib**

## FlatBuffers のパースに関する注意

- `root_as_...` を呼び出す際は、必ず `ssab` データの整合性を確認した上で呼び出してください。
- データの整合性が不安な場合は、`ssab` バイナリの先頭 4 バイトが `SSAB` という識別子（file_identifier）になっているかを確認してください。
