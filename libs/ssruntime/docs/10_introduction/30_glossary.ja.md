# 用語集

このガイドで使う用語です。1 つの概念には 1 つの語だけを使います。詳しい説明のある用語には、その説明のあるページを添えています。

## 1. ファイル

| 用語 | 意味 |
| :--- | :--- |
| sspj | SpriteStudio のプロジェクトファイル。以下の `ss*e` ファイルを束ねる |
| ssae | アニメーションのファイル。1 つの ssae が 1 つ以上のアニメーションを持つ |
| ssce | セルマップのファイル |
| ssee | エフェクトのファイル |
| ssse | サウンドのファイル |
| ssqe | シーケンスのファイル。複数のアニメーションを順に再生する設定を持つ |
| charmap | ビットマップフォントの定義ファイル（`.fnt`） |
| ssab | ssconverter が 1 つの ssae から生成する再生用バイナリ。その ssae が使うセルマップ・エフェクト・サウンド・charmap の情報を含む。スキーマは FlatBuffers |
| ssqb | ssconverter が ssqe から生成するシーケンス用バイナリ |

## 2. SpriteStudio の概念

| 用語 | 意味 |
| :--- | :--- |
| パーツ | アニメーションを構成する要素。親子の階層を持ち、種別（通常・ヌル・メッシュ・マスク・シェイプ・9 スライス・テキスト・インスタンス・エフェクト・オーディオなど）がある |
| セル | テクスチャから切り出した矩形の領域。パーツにセルを割り当てると、その絵が表示される |
| セルマップ | 1 枚のテクスチャと、そこから切り出すセルの一覧 |
| アトリビュート | パーツが持つ値（位置・回転・拡縮・不透明度・ユーザーデータなど）。キーフレームで時間とともに変化する |
| 描画優先度 | パーツを描く順番を決める値。小さいほど先に（奥に）描く。→ [マスク §2-1](../40_parts/40_mask.ja.md#2-1-スコープどの描画パーツにマスクが及ぶか) |
| 子アニメーション | インスタンスパーツが参照して再生する、別のアニメーション。→ [インスタンスパーツ](../40_parts/50_instance.ja.md) |
| 独立再生 | インスタンスパーツ・エフェクトパーツの設定。親のフレームではなく自分の経過時間で進む。→ [インスタンスパーツ §3](../40_parts/50_instance.ja.md#3-独立再生) |

## 3. Brain と Player

| 用語 | 意味 |
| :--- | :--- |
| Brain | `libssruntime`。アニメーションの状態を計算し、描画計画を出力する。→ [概要 §2](./10_overview.ja.md#2-brain-と-player-の分担) |
| Player | Brain を包み、読み込み・描画・イベント通知・音の再生をエンジン上で行う実装 |
| ssconverter | sspj を読み込んで ssab を生成するコンバータ。ライブラリ（`libssconverter`）と CLI（`ssconverter-cli`）がある |
| リソース | ssab を読み込んで作る、読み取り専用のデータ。C-API ではリソースハンドル、Rust では `AnimationResource`。複数の Context で共有できる。→ [ロードと初期化 §1](../30_core/10_initialization.ja.md#1-リソースと-context) |
| Context | 1 体分の再生状態と計算バッファ。リソースをバインドして使う |
| FrameData | Brain が 1 フレームごとに出力する FlatBuffers のバッファ。パーツの状態・描画計画・パーツカラーなどを含む |
| PartData | ssab に入っているパーツの静的な定義（ssab の `parts`）。フレームによって変わらない |
| SoA バッファ | ワールド行列や頂点のように、全パーツ分の値を 1 本の配列に並べて渡すバッファ。ポインタで直接読む。→ [描画ループ §1](../30_core/40_render_loop.ja.md#1-soa-バッファ) |
| DrawBatch | 同じテクスチャ・同じ合成モードで続けて描けるパーツのまとまり。Player は 1 つの DrawBatch を 1 回のドローコールで描ける。→ [描画ループ §2](../30_core/40_render_loop.ja.md#2-drawbatch-による描画) |
| `draw_order` / rank | `draw_order` は描画する順に並べたパーツのインデックス列。rank はその中の位置 |
| スロット | インスタンスパーツ・エフェクトパーツごとに Player が持つ、子の再生状態。`ss_instance_slot_*` / `ss_effect_slot_*` で操作する |
| 再生ヘッド | 現在の再生位置（フレーム番号）。サブフレーム再生では小数になる |
| サブフレーム | 整数フレームの間の状態を補間して描くこと。→ [再生制御 §6](../30_core/20_playback_control.ja.md#6-サブフレーム) |
| フレームスキップ | 描画が追いつかないとき、経過時間に合わせてフレームを飛ばして進めること |
| トラック / ソース | アニメーションミキシングの単位。トラックはポーズを重ねる層、ソースはトラックに載る 1 本のアニメーション。→ [アニメーションミキシング](../50_features/10_animation_mixing.ja.md) |
| オーバーライド | パーツのカラー・セル・表示を、実行時にキーフレームより優先して上書きする機能。→ [パーツオーバーライド](../50_features/20_part_overrides.ja.md) |
| writer | ステンシル（または被覆）に書き込むパーツ。純粋なマスク（マスクパーツなど）と、クリッピングを持つ描画パーツがこれにあたる。→ [マスク §1](../40_parts/40_mask.ja.md#1-概念とパーツの役割) |
