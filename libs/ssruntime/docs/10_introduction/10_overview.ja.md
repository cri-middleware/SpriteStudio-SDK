# 概要

このガイドは、`libssruntime` を使って、任意のゲームエンジンやプラットフォームに SpriteStudio の Player を実装する方法を説明します。

## 1. 読者

- 自作のエンジンや既存のエンジン（Unity・Godot など）に SpriteStudio の再生を組み込むエンジニア
- 組み込み環境や WebAssembly へ移植するエンジニア
- これらの作業を任された AI エージェント

## 2. Brain と Player の分担

`libssruntime`（以下 Brain）は、アニメーションの状態を計算するライブラリです。ファイルの読み込みも、描画も、音の再生も行いません。それらを行うのが Player です。計算を Brain に集めることで、補間やパーツカラーのような細かい規則がどの Player でも同じ結果になり、Player はエンジンとの橋渡しに専念できます。

| 領域 | Brain | Player |
| :--- | :--- | :--- |
| データ | 渡された ssab から、再生に必要な部分を展開する | ssab を読み込んで Brain に渡す。パーツ名やテクスチャのパスなどのメタデータは、FlatBuffers で ssab を直接読む |
| 時間 | 経過時間からフレーム番号を求め、ループと再生状態を管理する | 毎フレームの経過時間を渡す |
| 値 | キーフレームの間を補間し、親から子への継承を適用する | — |
| 変換 | パーツごとのワールド行列とローカル頂点を出力する | エンジンの座標系で描画する |
| 描画 | 描画計画（`DrawBatch`）を出力する | テクスチャを読み込み、ドローコールを発行する |
| イベント | そのフレームで通過したイベントを列挙する | エンジンのコールバックやシグナルに変換して通知する |
| サウンド | 再生の指示をイベントとして出す | 音声ファイルを読み込んで鳴らす |

## 3. コード例について

コード例は、C-API（`ssruntime.h`）を呼ぶ C++ で書いています。ほかの言語から使う場合は、その言語の FFI の書き方に読み替えてください。例の中で実在しない関数を使う場合は、例のそばにその旨を書いています。

WebAssembly 向けのバインディング（`wasm-bindgen`）は C-API とおおむね 1 対 1 に対応し、名前は `ss_runtime_` を外した形です。ポインタを返す関数は `_buf` と `_len` の 2 つに分かれます（例: `get_world_matrices_buf` / `get_world_matrices_len`）。
