# オーディオ

オーディオパーツのキーは、Brain の中では音を鳴らさず、`audios` のイベントとして報告されます（[イベント](../30_core/30_events.ja.md)）。Player は、そのイベントを受けてエンジンのオーディオ機能で音を鳴らします。

## 1. 準備

- **先に読み込んでおく。** 音声ファイルの読み込みやデコードには時間がかかります。イベントが来てから読み込むと音が遅れるので、アニメーションをセットアップするときなどに、ssab に入っている音声を先に読み込んでデコードしておいてください。
- **必要になるまでオーディオを起動しない。** 音声を使わないプロジェクトで、オーディオの仕組み（Web Audio API の `AudioContext` など）を起動して資源を使わないように、ssab に音声が入っていると分かったときに初めて起動してください。

## 2. 再生する条件

- `audios` のイベントの `sound_name` の音を鳴らします。
- **再生が逆方向に進んでいる間は鳴らさないでください。** 多くのオーディオ API は音声の逆再生に対応していません。判定には `ss_runtime_is_playing_forward()` を使います。これは、往復の復路や逆方向の設定を反映した、いまの進行方向を返します。速度は負の値を取らない（[再生制御 §5-1](../30_core/20_playback_control.ja.md#5-1-速度)）ので、速度の符号を見る必要はありません。
- **止めるのは鳴らすことで、通知ではありません。** `audios` のイベントは、進行方向にかかわらずホストに通知してください。鳴らすかどうかはオーディオの処理で決めます。イベントは、音を鳴らす以外の用途（字幕、振動、ログ）にも使われます。イベントそのものを止めると、音以外の利用者からもそのキーが見えなくなります。SSPlayerForGodot / SSPlayerForUnity / SSPlayerForRenPy は、どれも通知は必ず出し、内蔵の再生だけを止めています。
- `loop_num` は、名前はループ回数ですが、**再生する回数**です。1 以上の値で、その回数だけ繰り返し鳴らします。SpriteStudio のオーディオに無限ループはありません。

## 3. シークで鳴らさない

Player は、音をタイムラインの**キーを通過したときにだけ**鳴らします。SpriteStudio のエディタと違い、シークしても音の再生位置は合わせません。

ただし、シークすると、再生中でも停止中でも、Player が次に走らせる `update` で移動先のフレームのイベント（オーディオを含む）が報告されます（[イベント §3](../30_core/30_events.ja.md#3-イベントが報告されるフレーム)）。シーク（スクラブ）で音を鳴らしたくない場合は、シークの後の最初の `update` で報告されたオーディオのイベントを、Player が鳴らさないようにしてください。`play` の直後の開始フレームのオーディオは鳴らします。

## 4. 音の寿命

**再生の制御は、鳴っている音の寿命を持ちません。** `pause` / `resume` / `stop` / セットアップが終わらせる（または保持する）のは *アニメーション* で、既に鳴っている音には触れないでください。

- 一時停止で音も止めても、止められるのは既に鳴っている音だけです。止めている間に通過するはずだったキーの音は鳴らず、`resume` しても取り戻せません。保持のつもりが、音の抜けになります。
- `loop_num` は再生回数で、無限はありません。すべての音はいつか自然に終わります。停止やアニメーションの切り替えで音を消す Player は、音の暴走を防いでいるのではなく、最後まで鳴るはずの音を途中で切っています。アニメーションより長く鳴る音は、アニメーションのデータの問題です。

**例外は、Player 自身が消えるときだけです。** 破棄・無効化・シーンからの除去のときは、自分が鳴らした音をすべて止めてください。その音を持つものが誰もいなくなるためです。あわせて、「いますぐ音を止める」API をホストに公開してください。要点は、Player が自分で止めると決めない、ということです。

公式の Player はすべてこの方針です。Godot は `NOTIFICATION_EXIT_TREE` と破棄のとき、Unity は `OnDisable` / `OnDestroy`、Web は `destroy()`、Ren'Py は `hide` / `scene` で止め、それ以外では止めません。
