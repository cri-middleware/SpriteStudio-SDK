# 単語帳

## プロジェクトファイル
- sspj
    - SpriteStudio のプロジェクトファイルです。
- ssae
    - アニメーションのプロジェクトファイルになります。sspj ファイルに所属します。
    - 1つの ssae は1つ以上の複数のアニメーションを有してます。
- ssce
    - セルのプロジェクトファイルです。sspj ファイルに所属します。
- ssee
    - エフェクトのプロジェクトファイルです。sspj ファイルに所属します。
- ssse
    - サウンドのプロジェクトファイルです。sspj ファイルに所属します。
- ssqe
    - シーケンスのプロジェクトファイルです。複数の ssae のアニメーションを順番に再生する設定を持ちます。
- charmap
    - ビットマップフォントのプロジェクトファイルです。sspj ファイルに所属します。

## バイナリファイル
- ssab
    - アニメーション再生用バイナリファイルです。
    - ssab は 1つの ssae ファイルとその ssae が利用する ssce, ssee, ssse, charmap の情報を含んでいます。
- ssqb
    - シーケンス再生用バイナリファイルです。

## SpriteStudio 固有の概念
- セル (Cell)
    - 画像（テクスチャ）から切り出した一部の領域のことです。パーツにセルを割り当てることで画像が表示されます。
- パーツ (Part)
    - アニメーションを構成する要素（ノード）です。親子関係の階層構造を持ち、「通常」「ヌル」「メッシュ」「エフェクト」などの種類(PartType)があります。
- アトリビュート (Attribute)
    - パーツが持つプロパティ（座標、回転、スケール、不透明度、ユーザーデータなど）のことです。時間経過とともに値が変化します。

## SDK ・ ランタイム用語
- libssruntime / ssruntime
    - SpriteStudio7-SDK が提供する C-API のアニメーション再生コアライブラリです。時間管理とアニメーションデータの計算を担当し、描画は行いません。
- Player (プレイヤー)
    - ゲームエンジンなどの対象環境に合わせて、libssruntime をラップし、実際に画像のロードや描画処理（レンダリング）、イベント発火などを行う実装・ライブラリのことです。
- FrameData (フレームデータ)
    - libssruntime に再生時間を進めさせた（Updateした）結果得られる、そのフレームで描画すべき全パーツの計算済みアトリビュート情報（FlatBuffers形式）です。
- ssconverter / ssconverter-cli
    - sspj プロジェクトファイルを読み込み、最適化されたバイナリファイルである ssab などを生成するコンバートツールです。
- フレームスキップ (Frame Skip)
    - 描画処理が設定された FPS に追いつかない場合に、指定された経過時間に合わせて表示すべきフレームまで番号を飛ばして再生することです。
    - 他のツールや環境では「Time-Based Animation（時間軸ベースのアニメーション）」「Variable Frame Rate 再生」などと呼ばれることもあります。
    - libssruntime では、デルタタイムから適切なフレームを算出するこの機能を標準で提供しています。
