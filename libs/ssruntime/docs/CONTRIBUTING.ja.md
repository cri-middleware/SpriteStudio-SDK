# Player 移植ガイドの書き方

このガイド（`libs/ssruntime/docs/`）を編集・翻訳するときの規約です。読者は、Player を実装する人と、Player を実装する AI の両方です。

## 構成

- **章 = ディレクトリ、ページ = ファイル**。どちらも **10 飛ばし**で番号を付けます（`10_`, `20_`, `30_`…）。間に入れるときは `15_` などを使い、既存の番号を振り直しません。
- 章: `10_introduction` / `20_design` / `30_core` / `40_parts` / `50_features` / `60_troubleshooting`。
- 目次は `README.md`（英語）/ `README.ja.md`（日本語）。ページを増やしたら、目次の表と `mkdocs.yml` / `mkdocs.ja.yml` の `nav` の両方に加えます。ロケールごとに別にビルドするので、片方だけだとそのロケールでページが nav から消えます。`scripts/build-docs-tree.py` がどちらの漏れも検出します。
- H1 には番号を付けません。H2 は `## 1.`、H3 は `### 1-1.` の形で番号を付け、本文からは `§1-1` で参照します。

## ページの書き方

- **H1 の直後に、そのページで Player が何をするかを書きます。** 読むべきページかを、ここだけで判断できるようにします。
- **守るべきことは「〜してください」「〜しないでください」、選べることは「推奨します」**と書き分けます。
- **1 つの事実は 1 か所にだけ書きます。** 他のページからはリンクで参照します。同じことを 2 か所に書くと、片方だけが古くなります。
- **用語は [用語集](./10_introduction/30_glossary.ja.md) の意味で使います。** 1 つの概念に 2 つの語を使いません。新しい用語は用語集に加えます。
- コード例は C-API を呼ぶ C++ で書きます。実在しない関数（エンジンの描画処理など）を使うときは、例のそばにそう書きます。
- 経緯（「以前は〜だった」）、将来の予定、SDK の内部の実装（ソースのファイル名、内部の関数名）は書きません。
- 実装のチェックリストは置きません。本文の「〜してください」と同じことの繰り返しになるためです。

## 表記

- 製品名は **SpriteStudio**、ライブラリは **Brain**（`libssruntime`）、実装する側は **Player** と書きます。ファイル形式は小文字で **ssab** / **sspj** / **ssae** と書きます。C の関数群は **C-API** です。
- カタカナ語の長音は SpriteStudio の各リポジトリの多数派に合わせます。-er / -or で終わる語の多くは伸ばしません（エディタ・コンバータ・パラメータ・シェーダ・バッファ・ポインタ・アロケータ・リンカ・フォルダ・ブラウザ）。定着した語は伸ばします（ユーザー・プレイヤー・レイヤー・レンダラー・ラッパー・エミッター・サンプラー・キャラクター）。
- 送り仮名は省きません（呼び出し・書き込み・読み込み・切り替え・差し替え・割り当て）。「すべて」「ください」「できる」「とき」「こと」「など」はひらがなで書きます。「既定」を使い、「デフォルト」は使いません。
- 日本語と英数字の間には半角の空白を入れます。括弧は全角（）を使います。ラベルの後は半角のコロンと空白（`例: `）にします。
- **日本語の文字と文字の間で改行しません。** Chrome が改行を空白として描きます。

## 多言語

- **英語 = `NN_name.md`、日本語 = `NN_name.ja.md`**。同じディレクトリ・同じ名前・同じ番号で対にします。
- 各ページの先頭に言語の切り替えを置きます。
    - 日本語のページ: `> **日本語** | [English](./NN_name.md)`
    - 英語のページ: `> [日本語](./NN_name.ja.md) | **English**`
- **ページの中のリンクは同じ言語のページを指します。** 日本語のページは `.ja.md`、英語のページは `.md` へリンクします。
- **アンカーは言語ごとに違います**（見出しが違えばアンカーも違います）。日本語と英語をまたぐアンカーのリンクは張りません。

## 日英を揃える

すべてのページが日英そろっていて、**日本語が正本**です（食い違ったら日本語に従う、と英語の目次が宣言しています）。

1. 日本語のページ `NN_name.ja.md` を先に書く。
2. 同じ変更で英語のページ `NN_name.md` を直す。ページの中のリンクは **`.ja.md` を `.md` に** 変える。
3. ページを増やすときは対で加え、目次と両方の `nav` に登録する。

## リンクの検査

- すべての `.md` の相対リンクについて、リンク先のファイルと、アンカーが見出しから作られる id にあるかを確かめます。id は `mkdocs.base.yml` の `toc.slugify`（`pymdownx.slugs.slugify`、小文字）で作られます。
- 本文の中の古いファイル名や章番号（リンクでない `§N`）はリンクの検査をすり抜けるので、`grep` で別に確かめます。
