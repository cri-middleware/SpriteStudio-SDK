# Player 移植ガイド ドキュメント規約（構成・多言語）

このガイド（`libs/ssruntime/docs/`）を編集・翻訳する際の規約です。

## ディレクトリ / ファイル構成

- **大項目 = ディレクトリ、中項目 = ファイル**。両方とも **10 飛ばし**で採番（`10_`, `20_`, `30_`…）。間に挿入したいときは `15_` などを使い、既存を振り直さない。
- カテゴリ: `10_introduction` / `20_design` / `30_core` / `40_components` / `50_reference` / `60_tooling`。
- 索引は `README.md`（英語）/ `README.ja.md`（日本語）。
- **H1 見出しは番号を付けない**説明的タイトル。順序は dir/ファイル番号と索引で表現する。

## 多言語（i18n）規約

- **英語 = `NN_name.md`、日本語 = `NN_name.ja.md`**（リポジトリ全体の規約に準拠）。同じディレクトリ・同じ slug・同じ番号でペアにする。
- 各ページ冒頭に**言語スイッチャ**を置く:
  - 日本語ページ: `> **日本語** | [English](./NN_name.md)`
  - 英語ページ: `> [日本語](./NN_name.ja.md) | **English**`
- **内部リンクは同一言語**を指す。日本語版は `.ja.md`、英語版は `.md` へリンクする。
- **アンカーは言語別**（見出し文字列が違えばアンカーも違う）。日英をまたぐアンカーリンクは張らない。

## 翻訳の進め方

現状、英語版は各ページとも「未翻訳スタブ（`.md`）」で、日本語版へ誘導しています。翻訳する場合:

1. 対象の英語スタブ `NN_name.md` を開く（冒頭のスイッチャ行は残す）。
2. 対応する `NN_name.ja.md` の内容を英訳し、本文を置き換える。
3. 本文中の内部リンクの**サフィックスを `.ja.md` → `.md` に反転**する（英語ページは英語ページへリンク）。
4. 英語索引 `README.md` の該当リンクは既に `.md` を指しているので変更不要。
5. 翻訳が揃ってきたら、外部（`README.md` / `libs/ssruntime/README.md` 等）からの深いリンクも `.ja.md` → `.md` に順次差し替える。

## リンク検証

- 全 `.md` の相対リンクを normpath で存在確認する。
- プレーンテキスト中の**旧ファイル名・章番号ラベル**はリンクチェックをすり抜けるので、`grep` で別途確認する。
