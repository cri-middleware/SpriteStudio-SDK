# はじめに (Introduction)

このドキュメントは、`libssruntime` を使用して、独自のゲームエンジンやプラットフォーム向けの SpriteStudio 7 アニメーション再生プレイヤー（Player）を実装するためのガイドラインです。

## ドキュメントの目的

`libssruntime` は、アニメーションの計算ロジック（補間、時間管理、データ展開）を専門に扱う「頭脳」としての役割を担いますが、実際の描画（レンダリング）やプラットフォーム固有の処理は行いません。この設計により、高い移植性を実現しています。

本ガイドでは、Player を実装するにあたっての基本的なアーキテクチャ、実装の順序、考慮すべき制限事項、および `overall.sspj` を使用した段階的な機能検証ロードマップを解説します。

## 対象読者

- 自作ゲームエンジンに SpriteStudio 7 のサポートを追加したいエンジニア
- Unity や Godot などの既存エンジン向けに、より高度なカスタマイズを施した Player を作成したい開発者
- リソース制限の厳しい組み込み環境や WebAssembly 環境への移植を行う開発者

## サンプルコードについて

本ドキュメント内のコードスニペットは、主に **C++** を想定して記述されています。
`libssruntime` は C-API を提供しているため、C#、Rust、Go、JavaScript (WebAssembly) など、お使いの言語の FFI (Foreign Function Interface) 構文やメモリ管理モデルに合わせて適宜読み替えて参考にしてください。
